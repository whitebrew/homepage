# Whitebrew Agents

This document defines the roles and responsibilities of the AI agents collaborating on the Whitebrew homepage redesign.

## 1. Role Definitions

### 🏛️ Architect Agent (Primary)
- **Role:** High-level planning, technical stack selection, and structural design.
- **Responsibilities:**
  - Define the project's overall vision and roadmap.
  - Ensure technical feasibility for GitHub Pages (HTML/JS/CSS).
  - Review and approve structural changes in `index.html`.

### 🎨 Design & UI Agent
- **Role:** Visual aesthetics, styling, and user experience.
- **Responsibilities:**
  - Define the "Future-Oriented IT SW Company" visual identity.
  - Implement modern CSS (Flexbox, Grid, CSS Variables, Glassmorphism).
  - Select typography and color palettes (Accent colors: Blue/Violet).

### 🛠️ Developer Agent
- **Role:** Implementation, optimization, and bug fixing.
- **Responsibilities:**
  - Write clean, semantic HTML5 and performant Vanilla JavaScript.
  - Optimize assets (images, icons) for fast loading.
  - Ensure cross-browser compatibility and mobile responsiveness.

### 📝 Content & Marketing Agent
- **Role:** Copywriting and strategic messaging.
- **Responsibilities:**
  - Draft compelling copy for the "Monolinc" mention.
  - Maintain a consistent tone of voice (Modern, Bold, Trustworthy).

## 2. Collaboration Protocol
- Agents must document all significant changes in `docs/plans/`.
- The Architect Agent oversees the alignment with the original user intent.
- All code changes must be verified against the GitHub Pages deployment constraints.
